# ZeroTick Public Assets

Public assets for ZeroTick. `docs/` holds documentation screenshots hotlinked by the GitBook docs site
(SHA-pinned raw URLs), under two subtrees:

- `docs/guides/` holds step-by-step product-guide screenshots.
- `docs/gitbook/` holds screenshots for the GitBook concept pages.

**This repository is public.** Never commit anything sensitive here (no secrets, tokens, internal URLs, or
private data). Treat `docs/` as append-only once pages are live: deleting or renaming an image breaks the
SHA-pinned raw URLs in already-published doc revisions.
